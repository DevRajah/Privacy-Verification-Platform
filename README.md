Privacy Verification Platform is an MSc Software Engineering dissertation project focused on reducing unnecessary disclosure of personal information during public-service verification processes.

Instead of sharing full identity documents, the platform enables service providers to request verification of specific attributes (such as student status or housing eligibility) through a consent-driven workflow. Users maintain control over their personal information through approval, rejection, revocation, and transparency mechanisms.

The system is designed to address challenges in consent lifecycle management, verification transparency, access control, and public-service integration while demonstrating a practical privacy-preserving verification architecture.
